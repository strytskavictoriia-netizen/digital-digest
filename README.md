# 🗞 Шаблон щоденного дайджесту в Telegram

Щоранку бот збирає новини на обрану тему з сайтів, Telegram-каналів, YouTube і Reddit. Claude (за твоєю підпискою) відбирає найважливіше, пише стислий випуск українською і публікує його **одним повідомленням** у твій Telegram-канал. Кожна новина веде на сторінку з подробицями, рекомендаціями й джерелами.

Один репозиторій = один дайджест = один канал.

## Як створити свій дайджест

1. Пройди інструкцію з віконечками: **https://claude.ai/artifact/X7f1cfSZRegG6PsYcBKmdu**
2. Коротко:
   - тут, на GitHub: **Use this template → Create a new repository → Private**;
   - відкрий новий репозиторій у Claude (вкладка Code);
   - напиши: **«Зроби дайджест про …»**.

Далі Claude проведе тебе кроками:
- розпитає про тему, читачів і формат;
- сам знайде джерела і спитає, які додати від тебе;
- допоможе з каналом, ботом і ключами;
- зробить тестовий випуск.

## Як змінювати дайджест потім

Просто напиши Claude в цьому репозиторії, наприклад:
- «додай джерело https://t.me/…»
- «прибери Reddit, забагато шуму»
- «зроби 8 новин замість 12»
- «чому сьогодні не прийшов дайджест?»

Можна й вручну: усе, що стосується теми й формату, лежить у [`config.yaml`](config.yaml) і редагується прямо на GitHub (✏️ → Commit changes).

## Що де

| Файл | Що там |
|---|---|
| `config.yaml` | назва, тема, читачі, напрями, формат, джерела |
| `prompts/` | інструкції для Claude (зазвичай не чіпати) |
| `.github/workflows/` | запуски: щоденний, тижневий, наглядач |
| `archive/` | усі випуски (з'являться після першого запуску) |
| `.claude/skills/digest-builder/` | скіл, за яким Claude створює й супроводжує дайджест |
