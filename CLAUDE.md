# Digest repository

This repo is a daily Telegram digest engine. For anything about creating, configuring, launching,
changing sources/format of, or troubleshooting the digest, use the **digest-builder** skill
(`.claude/skills/digest-builder/SKILL.md`). The user is usually non-technical and writes in
Ukrainian — answer in Ukrainian and keep explanations plain.

If `config.yaml` still contains `topic: (опис теми)`, the digest has not been set up yet — start
the skill's "new digest" flow.
